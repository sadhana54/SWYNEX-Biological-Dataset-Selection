# SWYNEX-Biological-Dataset-Selection
# Bioinformatics Internship – Task 1

## Project Title
Exploring the Human TP53 Gene Sequence Using NCBI

## 1. Introduction
Bioinformatics is the application of computational tools to biological data. This project focuses on exploring the human TP53 gene sequence using publicly available biological information from the NCBI database.

## 2. Dataset Source
- Database: National Center for Biotechnology Information (NCBI)
- Organism: Homo sapiens (Human)
- Gene name: TP53
- Gene ID: 7157
- Chromosome: 17
- Reference genome: GRCh38.p14
- Reference sequence: NC_000017.11

Source link: https://www.ncbi.nlm.nih.gov/gene/7157

## 3. Dataset Size
The selected TP53 genomic region extends from position 7,668,421 to 7,687,490 on chromosome 17.

Total genomic region length: 19,070 base pairs (bp).

## 4. Research Question
What is the length and basic nucleotide composition (A, T, G and C) of the human TP53 gene sequence?

## 5. Objective
- To access a biological sequence from a public database.
- To understand the structure of a DNA sequence.
- To identify the length of the selected genomic region.
- To develop basic knowledge of biological data analysis.

## 6. Methodology
1. Access the NCBI Gene database.
2. Search for the human TP53 gene.
3. Identify its reference genome and genomic coordinates.
4. Obtain the relevant DNA sequence in FASTA format.
5. Document the dataset information for further analysis.

## 7. Expected Outcome
This project will provide basic knowledge of DNA sequence databases and introduce the use of computational methods in Bioinformatics.

## 8. Conclusion
This project is an introductory step towards understanding biological datasets and their applications in Bioinformatics research.
